# Google Go Style Guide (Skill)

Agent skill for **Google Go style**: guide, style decisions, and best practices
when writing or reviewing Go.

- Writing or reviewing Go code for naming, formatting, errors, godoc, tests, or
  APIs.
- Keywords: gofmt, MixedCaps, Google Go style, imports, `%w`, table-driven
  tests, option structs, `context.Context`.

# API REST Design Principles (Skill)

Agent skill for **Fielding REST constraints**: resources vs representations,
statelessness, uniform interface, HTTP verbs, status codes, and RMM levels.

## When to use

- **Starting or reviewing** a REST HTTP API.
- **Keywords**: REST principles, Fielding, RMM, status codes, HTTP verbs,
  statelessness, uniform interface.
- **Decisions**: whether an API is “RESTful enough”; Level 2 vs Level 3;
  correct status for create/async/validation.

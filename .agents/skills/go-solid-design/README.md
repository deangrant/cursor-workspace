# SOLID Design Principles — Go (Skill)

Agent skill for applying **SOLID** (SRP, OCP, LSP, ISP, DIP) when designing and
reviewing **Go** code: packages, small interfaces, composition, constructor
injection, and dependency direction.

## When to use

- Design or review Go packages, interfaces, and public APIs for
  maintainability.
- Keywords: SOLID, SRP, OCP, LSP, ISP, DIP, consumer-owned interfaces, accept
  interfaces return structs, dependency injection, import graph, embedding.

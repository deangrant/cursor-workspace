# Technical Writing — TW One Reference

Google Technical Writing One fundamentals and lint checklist. See
[SKILL.md](SKILL.md) for the workflow. See [examples.md](examples.md) for
rewrites.

## Document-level

| Practice | Detail |
| -------- | ------ |
| Scope + non-scope | State what is in and reasonably out |
| State audience | Roles, prerequisites, prior reading |
| Front-load | First paragraph may be all busy readers see |
| Revise page one | Hardest page; iterate heavily |
| Compare/contrast | Anchor new ideas to familiar tech |
| Planning questions | Who? Goal? Already knows? Should know after? → outline |
| Section long topics | Organize to reader needs |

## Words and terminology

| Practice | Detail |
| -------- | ------ |
| Define unfamiliar terms | Link, define, or glossary |
| Consistent terminology | One name per thing; declared short forms |
| Acronyms | Expand on first use |
| Ambiguous pronouns | Fix *it/they/this/that* null pointers |

## Active voice

Prefer **actor + verb + target**. Passive may hide the actor and force extra
reader work. Imperative procedure steps ("Download the package") are active.

## Clear and short sentences

| Practice | Detail |
| -------- | ------ |
| Specific verbs | Prefer action verbs over *be*, *occur*, *happen* |
| Reduce *there is/are* | Real subject + verb |
| One idea per sentence | Split multi-thought sentences |
| Long sentence → list | Expand embedded enumerations |
| Cut filler | "triggers" not "causes the triggering of" |
| Quantify | Numbers over hype adverbs |

## Lists and tables

| Practice | Detail |
| -------- | ------ |
| Bulleted | Order irrelevant |
| Numbered | Order matters; start with imperative verb |
| Parallel items | Grammar, category, capitalization, punctuation, voice |
| Introduce with colon | "The following steps:" |
| Tables | Headers; concise cells; parallel columns |

## Paragraphs

| Practice | Detail |
| -------- | ------ |
| Strong opening | Central point first |
| Single topic | Delete or move off-topic sentences |
| Length | ~3–5 sentences; split >7 |
| What / why / how | Good paragraphs answer all three |

## Audience

- Identify **role + proximity**; list the learning gap (needed − current).
- **90% rule:** if ≥10% of readers won't know a term → explain or link.
- Avoid idioms and cultural references for international readers (see
  [reference-global-inclusive.md](reference-global-inclusive.md)).

## Punctuation (quick)

- Oxford comma in lists of three+.
- Colon before introduced lists.
- No comma splices; semicolon only for tightly related independent clauses.
- Period vs semicolon: distinct thoughts vs highly related ones.

## Official TW One ship checklist

- [ ] Define unfamiliar terms; consistent terminology; no ambiguous pronouns.
- [ ] Prefer active over passive.
- [ ] Specific verbs; reduce *there is/are*.
- [ ] One idea per sentence; long sentence → list; cut unneeded words.
- [ ] Numbered = order; parallel items; imperative steps; colon intro.
- [ ] Strong opening sentence; single topic per paragraph.
- [ ] Audience fit; what they must learn is clear.
- [ ] Scope, audience, key points up front.

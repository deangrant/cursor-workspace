# Technical Writing (Skill)

Senior-level technical writing for agents: audience-first planning, clear active
prose, scannable structure, error-message UX, sample code, global/inclusive
language, and CL/PR descriptions.

Grounded primarily in **Google Technical Writing One / Two / Error Messages**,
extended with **Microsoft Style Guide** voice, bias-free language, global
English, and Google eng-practices CL descriptions.

## When to use

- Drafting or revising READMEs, tutorials, API docs, design notes, release notes.
- Error / CLI / UI failure copy.
- Pull request or changelist descriptions.
- Clarity rewrites ("make this read like a tech writer wrote it").

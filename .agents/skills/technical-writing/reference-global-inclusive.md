# Technical Writing — Global and Inclusive Reference

Beyond Google TW: Microsoft Style Guide voice, bias-free language, and global
English for worldwide / UI audiences.

## Microsoft writing voice (top practices)

Warm, relaxed, crisp, clear.

| Principle | Practice |
| --------- | -------- |
| Bigger ideas, fewer words | Crisp minimalism |
| Write like you speak | Read aloud; cut jargon |
| Project friendliness | Natural contractions where appropriate |
| Get to the point fast | Front-load; clear next steps |
| Be brief | Enough to decide; prune excess |
| Sentence case | Avoid Title Case Everywhere |
| Punctuation in UI | Often skip end periods on short labels/headings |
| Oxford comma | Lists of three+ |
| Spacing | One space after `.?!:` |
| Strong verbs | Cut *you can*, *there is/are* |

Docs vs chatty UI: prefer clarity for translation when content will be localized
(see Global English).

## Bias-free language

| Prefer | Avoid |
| ------ | ----- |
| chair, moderator | chairman |
| humanity, people, humankind | mankind |
| sales representative | salesman |
| workforce, staff | manpower |
| allowlist / blocklist | (prefer precise non-loaded terms) |

Generic pronouns: prefer *you*, plurals, role nouns, or singular *they* —
never *he/she* or *s/he* as generic.

Avoid militaristic / ableist / culturally loaded metaphors in examples. Use
diverse, realistic example names and locales.

## Global English (translatable)

Assume non-native readers and possible MT/localization.

| Practice | Why |
| -------- | --- |
| Short, simple sentences | Complex clauses break MT |
| Lists and tables | Replace dense paragraphs |
| Include *that* / *who* and articles | Clarify structure |
| Sentence-style capitalization | Proper nouns only |
| No idioms / colloquialisms / culture-specific jokes | Hard to localize |
| Avoid long modifier stacks | Ambiguity |
| Active voice; imperative in procedures | Clear agency |
| Keep modifiers next to what they modify | Watch *only* placement |
| Prefer ≤2 clauses linked by and/or/but | Parsing difficulty |

Translation ≠ localization: you write **translatable English**; localizers adapt
culture and formats.

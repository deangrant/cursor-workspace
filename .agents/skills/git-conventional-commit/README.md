# Git Conventional Commit (Skill)

Agent skill for drafting a single **Conventional Commits 1.0.0** message from
`git status` / `git diff`. Does not run `git commit`.

## When to use

- User asks for a commit message or conventional commit text.
- Slash command `/git-conventional-commit` (thin pointer into this skill).

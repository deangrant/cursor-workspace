# Git Conventional Commit

Read and follow the **git-conventional-commit** skill at
[`.agents/skills/git-conventional-commit/SKILL.md`](../skills/git-conventional-commit/SKILL.md).

Run `git status` and `git diff` (or use status/diff the user provides), then
produce one Conventional Commits 1.0.0–compliant commit message. Do **not** run
`git add` or `git commit`; do not modify repository state.

# Code Review (Diff)

Read and follow the **code-review** skill at
[`.agents/skills/code-review/SKILL.md`](../skills/code-review/SKILL.md).

**Review scope:** `diff`

Run `git status` and `git diff` (or use status/diff the user provides), then
perform the read-only review. Do **not** modify, edit, or rewrite code; output
markdown findings only.

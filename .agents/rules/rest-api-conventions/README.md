# REST API Conventions Rule

Opt-in rule (`alwaysApply: false`) for consistent REST URI, verb, status, and
envelope conventions while editing API code.

## When to use

Enable when working on HTTP handlers, OpenAPI specs, or API design reviews.

## Usage

Copy this folder into a project’s `.agents/rules/` (with `.cursor/rules` symlink)
or `.cursor/rules/`, then enable the `.mdc` rule.
